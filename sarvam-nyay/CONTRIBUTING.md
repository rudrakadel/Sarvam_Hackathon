# Contributing

Thanks for your interest in this project. Issues and pull requests are welcome.

## Reporting bugs

Open an issue and include what you expected, what actually happened, a minimal reproduction, and your environment.

## Pull requests

1. Fork and create a feature branch from `main`.
2. One logical change per PR.
3. Add or update tests.
4. Run the test suite locally before submitting.
5. Follow the existing code style.

## Code of conduct

Be respectful. Disagree on ideas, not people.
